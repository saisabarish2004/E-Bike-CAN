# E-Bike CAN

**CAN communication, UART integration, BMS, cluster, and controller experiments for an electric bike**

---

This repository contains communication and control experiments developed for an electric bike system.

The work focuses on CAN bus communication between vehicle subsystems, UART communication, BMS data, cluster data, and controller-side integration.

## What's Inside

| Module | Description |
|---|---|
| **BMS** | Battery Management System communication and data |
| **Cluster** | Vehicle cluster communication and display data |
| **Main Controller** | Main vehicle control experiments |
| **CAN Transmitter** | CAN frame transmission |
| **Bluepill Transmitter** | STM32 Blue Pill based communication tests |
| **UART Tests** | UART communication and debugging |
| **Receiver** | CAN/UART receiving experiments |
| **Test Functions** | Communication and functional testing |

## Concepts Covered

- CAN Bus
- CAN Transmit / Receive
- CAN IDs
- Standard and Extended CAN IDs
- BMS Communication
- Cluster Communication
- UART
- STM32
- Multi-node Communication
- CAN-to-UART Data Conversion
- Vehicle Controller Communication

## Purpose

The projects are used to understand and implement communication between different subsystems of an electric vehicle prototype.
